**Date:** 2026-11-15  
**Tool Repository:** `vidipt9090/FlakeGuard`

**Pinned Ref:** `@main`

## 1. Reusable Workflow (`.github/workflows/scan.yml`)

The reusable workflow in `FlakeGuard` specifies:
```yaml
name: FlakeGuard Scan (Reusable Workflow)
on:
  workflow_call:
    inputs:
      repo_path:
        default: "."
        type: string
      n_runs:
        default: 3
        type: number
    secrets:
      GEMINI_API_KEY:
        required: false
      OPENAI_API_KEY:
        required: false

permissions:
  contents: write
  pull-requests: write
```

---

## 2. Caller Workflow in Demo Repo (`.github/workflows/triage.yml`)

```yaml
name: FlakeGuard CI Triage
on:
  push:
    branches: [main, develop]
  pull_request:
    types: [opened, synchronize, reopened]
  workflow_dispatch:

permissions:
  contents: write
  pull-requests: write

jobs:
  triage:
    uses: vidipt9090/FlakeGuard/.github/workflows/scan.yml@main
    with:
      repo_path: "."
      n_runs: 3
    secrets: inherit
```

---

## 3. Approval Mechanism & Labels

- **Label:** `approve-quarantine`
- **Workflow Permissions:** `contents: write` (commits to branch / quarantine.json) and `pull-requests: write` (posts triage comment).
- **Rule:** Automated quarantine is strictly refused on deterministic bugs (403 refusal) to protect maintainers against masking real code regressions.
