## 2. Canonical Live LLM Provider Selection

- **Primary Hosted Provider for Demo & CI:** `GeminiProvider`
  - Environment variable: `GEMINI_API_KEY`
  - Model: `gemini-1.5-pro` / `gemini-1.5-flash`
  - Justification: Fast token generation, native structured JSON support, reliable rate limits for CI runs.
- **Local Fallback Provider:** `LocalOllamaProvider`
  - Model: `llama3:8b` via `http://localhost:11434`
  - Justification: 100% offline, zero-cost, privacy-preserving execution.
- **Deterministic Evaluation Fallback:** `CachedReplayProvider`
  - Justification: Reproduces published benchmark results deterministically without network access.
