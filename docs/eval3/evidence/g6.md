## 3. Fork PR Isolation
When a PR is opened from an external fork without repository secret access (`is_fork=True`), the bot displays an informational notice and falls back to deterministic evidence heuristics:
```markdown
> ℹ️ **Notice:** Fork PR detected (repository secrets unavailable). Triage evaluated using local deterministic evidence heuristics.
```
