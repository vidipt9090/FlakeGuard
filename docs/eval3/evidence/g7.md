## 2. Security & Integrity Behaviors Verified

### A. Non-Writer Refusal
- `scripts/approve_quarantine.py` queries `GET /repos/{repo}/collaborators/{username}/permission`.
- Only users with `admin`, `write`, or `maintain` permission are authorized to approve quarantine.
- Non-collaborators and external contributors without write access are rejected with an authorization error.

### B. Real-Bug Quarantine Refusal (403 Forbidden)
- When a deterministic failure or real code defect (e.g. `test_case_22`, `test_total_rounds_correctly`) is requested for quarantine:
  - The API responds with `HTTP 403 Forbidden`:
    `"Quarantine refused: deterministic test failure represents a real code regression. Automated quarantine blocked."`
  - Prevents developer error from accidentally masking production defects.

### C. Idempotency & De-duplication
- When an already-quarantined test is approved a second time, the entry in `quarantine.json` is updated in place without duplicate entries (`test_append_to_quarantine_idempotent` passed).
